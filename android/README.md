# OpenCARWINGS SMS Gateway using Android

You can use your old Android smartphone (Android 1.6 and higher).

APK: [Releases](https://github.com/developerfromjokela/opencarwings-sms/releases/latest)

To set it up, you'll have to enter values shown in the app, into your SMS provider settings, found on the website.

![Näyttökuva 2025-10-17 kello 16 34 35](https://github.com/user-attachments/assets/fbfaca8b-9745-49ab-a9a6-9ec37abcd2f5)

![Näyttökuva 2025-10-17 kello 15 50 23](https://github.com/user-attachments/assets/1e831959-3de1-43ff-b2e3-0500f43249db)

Press connect. If everything is entered correctly, communication will be successful and phone will listen for SMS messages. Keep phone plugged to a charger and don't turn off the screen.
