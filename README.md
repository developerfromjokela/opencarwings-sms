# OpenCARWINGS SMS Gateway

Run your own SMS sending gateway using your phone, or modem.

You can use your old Android smartphone (Android 1.6 and higher).

Java is compatible with any AT-compatible modem, as long as it can send SMS in PDU and/or text.

APK and JAR: [Releases](https://github.com/developerfromjokela/opencarwings-sms/releases/latest)

To set it up, you'll have to enter values shown in the app, into your SMS provider settings, found on the website.
